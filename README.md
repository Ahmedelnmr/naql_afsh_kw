# Naql Afsh Kuwait (نقل عفش الكويت)

A one-page landing site for furniture moving in Kuwait.

## What's inside

- Static, mobile-first Arabic (RTL) website: HTML, CSS and vanilla JavaScript.
- Click-to-call and WhatsApp contact buttons with conversion tracking hooks.
- SEO basics: structured data, meta tags.
- No build step and no dependencies.

## Run locally

```bash
git clone https://github.com/Ahmedelnmr/naql_afsh_kw.git
cd naql_afsh_kw
npx serve .
```

Or open `index.html` in a browser.

## Deploy

Works on any static host (GitHub Pages, Netlify, Vercel, Cloudflare Pages).
